# Neighbourhood Rider

This repository now contains a single application:

- [backend](/home/maina/neighbourhoodrider/backend) - the Next.js full-stack MVP for the Neighbourhood Rider single-admin delivery service

## Active stack

- Next.js App Router
- MongoDB with Mongoose
- Tailwind CSS
- M-PESA STK Push

## Main app paths

- [backend/src/app](/home/maina/neighbourhoodrider/backend/src/app)
- [backend/src/components](/home/maina/neighbourhoodrider/backend/src/components)
- [backend/src/lib](/home/maina/neighbourhoodrider/backend/src/lib)
- [backend/src/models](/home/maina/neighbourhoodrider/backend/src/models)

## Run locally

```bash
cd backend
npm install
npm run dev
```
